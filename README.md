# Black Valley

South Wales, winter 1984. 5×5, 25 lines with cascades, four features (The Knock, The Pit, The Fire, The Village
Fights Back), three bonuses (The Strike, The Uprising, Final Stand), six modes, 20,000× max win. For Engine (Stake).
